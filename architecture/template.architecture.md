# Architecture: System template

1. Source controlled
2. Pipelines (CI/CD)
3. Hosting: including domain and SSL certificate(s)
4. Backend
5. Interface: responsive frontend
6. Observability: metrics, events, logs and traces (MELT) using open telemetry
7. Database: relational, noSQL and messaging systems
8. Authentication AuthN
9. Authorization: AuthZ
10. Resiliency: retries, circuit breakers, timeouts, rate limiter, fallback and hedging
11. Analytics
12. Payments
13. Ads
